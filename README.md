# BRUSAN · Desarrollo Visual

Official landing website for **BRUSAN (Desarrollo Visual)** — technical visual studio based in Gualeguaychú, Entre Ríos, Argentina.

## Features
- **WebGL Wave Shader Header**: Interactive light beam caustics and simplex noise background.
- **Three.js 3D Realistic Glass Logo**: Physically accurate glass transmission with subtle ambient floating motion.
- **Interactive Portfolio Accordion**: Dynamic hover-expanding showcase for commercial cartelería, CGI stills, and reels.
- **Cloudflare Pages Ready**: Self-contained static site structure with zero build steps required.
